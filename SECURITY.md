# Security Policy - Bloco Praieira

## Reporting a Vulnerability

Se você descobrir uma vulnerabilidade de segurança neste projeto, por favor nos informe de forma responsável.

**Como reportar:**
- Email: blocopraieira@gmail.com
- Assunto: [SECURITY] Descrição breve
- Inclua detalhes técnicos e passos para reproduzir

**Não divulgue publicamente** a vulnerabilidade até que tenhamos tempo para corrigi-la.

## Políticas de Segurança

- ✅ Atualizações regulares de dependências
- ✅ Headers de segurança HTTP implementados
- ✅ Sem armazenamento de dados sensíveis
- ✅ HTTPS obrigatório em produção
- ✅ CSP e proteção XSS

Agradecemos sua ajuda em manter o projeto seguro!
